# [While Loop](https://www.geeksforgeeks.org/problems/while-loop/1)
## Easy
Given a number n, print all numbers from 0 to n in increasing order in a single line using a while loop.Examples: Input: n = 3
Output: 0 1 2 3
Explanation: Numbers from 0 to 3 in increasing order are 0 1 2 3.Input: n = 5Output: 0 1 2 3 4 5Explanation: Numbers from 0 to 5 in increasing order are 0 1 2 3 4 5.
